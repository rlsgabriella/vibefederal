# Vibe Federal

Landing page de apresentação da Vibe Federal, feita com React + Vite.

## O que é a Vibe Federal

A Vibe Federal é uma plataforma de materiais de estudo voltada para quem se prepara para concursos de Institutos e Universidades Federais. O foco é oferecer mapas mentais e trilhas de estudo organizadas por concurso, com linguagem clara e visual, para que a preparação seja mais leve e eficiente.

## O que tem no site

- **Hero** com vídeo de fundo, apresentando a proposta da marca
- **Carrossel** com os principais concursos cobertos
- **Trilhas de estudo** organizadas por instituição (IFCE, IFPI, IFC, IFAL etc.)
- **Dicas de estudo** em formato de post-its interativos
- **Página Sobre** contando a história da Vibe Federal
- **Página Materiais** com aviso de novidades em breve
- **Botão flutuante** de contato via WhatsApp

## Como rodar

```bash
npm install
npm run dev
```

Acesse em `http://localhost:5173`
